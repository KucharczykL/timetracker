# CLEAN-02: Remove legacy PlayEvent and GameStatusChange storage — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delete the `PlayEvent` and `GameStatusChange` models, their tables, the
migration-only modules written to convert off them, and every reference in code,
tests, fixtures and docs — `make check` green throughout.

**Architecture:** Five ordered commits, each independently green (per the spec's
own numbering, not execution order): **A** neutralizes the three historical
migrations that call into legacy-only code; **D0** moves the sample fixture off
legacy rows onto the event store (must land **before** B — it removes the last
non-migration caller of the modules B deletes); **B** deletes the now-unreferenced
migration-only modules and their tests; **C** drops the two tables the ordinary
Django way (`DeleteModel`, autogenerated); **D** sweeps the remaining code, tests
and fixtures.

**Tech Stack:** Django 6, PostgreSQL 18, pytest/pytest-django, the project's
event-sourcing layer (`games/events/*`, `games/commands/*`, `games/projectors/*`).

**Spec:** [`docs/superpowers/specs/2026-09-11-clean-02-legacy-table-removal.md`](../specs/2026-09-11-clean-02-legacy-table-removal.md)
— the plan argues from the spec, so the spec travels with it; executors read
both. The spec's §Commit D0 is the authoritative rationale for every identity/
reference-derivation rule in Tasks 2–4 below; where a step here says "per §Commit
D0", read that section before writing the code.

## Global Constraints

- Gate is full `make check` (lint, format-check, mypy, vale, ts-check, vitest,
  the entire pytest suite **including `e2e/`**). Never verify with a hand-picked
  subset. `make check-fast` is for iterating only.
- Execution order is **A, then D0, then B, then C, then D** — not alphabetical.
  Commit B is not reachable until D0 lands (three of its six deleted modules
  have a live caller in `load_sample_data.py` until D0 replaces it).
- Never write to a `GeneratedField` (`duration_calculated`, `duration_total`,
  `price_per_game`, `days_to_finish`).
- Nothing destroys a record via `.delete()` outside migrations/fixture-loading
  scaffolding — this plan's deletions are schema/module deletions, not row
  deletions through the app's removal path, so `games/removal.py`'s
  `remove()`/`restore()` convention does not apply here.
- No dispatch inside a transaction wrapped by `run_in_transaction` — `dispatch()`
  and `rebuild_projections()` open their own; do not wrap either in an outer
  `@transaction.atomic` beyond what the existing code already has.
- Regenerating `games/fixtures/sample.yaml.gz` (Task 5) needs a real production
  dump (`make fetch-dump` / `make restore-dump`) and cannot be done from a bare
  checkout — flag this to whoever executes Task 5 before they start it.

- [ ] **Step 4: Add `_shift_effective_time` as a module-level helper**

Beside `_midnight`/`_floor_ms`:

```python
def _shift_effective_time(value, offset):
    """Shift a day-precision temporal value; leave an unknown one alone.

    The conversion passes (#684, #1038) only ever wrote a day value or an
    unknown one, so those are the only two shapes this command needs to
    handle. Any other precision raises rather than shipping an unjittered
    date — the coarser shapes (month/year/decade/range) don't currently
    occur in production events, and shifting one wrong is worse than
    refusing it loudly.
    """
    if value is None:
        return None
    if value.precision is not TemporalPrecision.DAY:
        raise CommandError(
            f"Event states a {value.precision} value ({value.canonical!r}); "
            "the anonymizer only knows how to shift a day value."
        )
    return TemporalValue.from_day(value.lower_bound + offset, qualifier=value.qualifier)
```

- [ ] **Step 5: Add `_reassign_event_identities`, called from `_anonymize`**

Add this method to `Command`, and read it against §Commit D0's "Identity" table
in the spec before trusting it verbatim — it implements that table's five rules

```python
    @staticmethod
    def _reassign_event_identities(game_offsets, game_replacements):
        """Shift, blank and re-key every event, then re-derive every
        event-table identity from the recorded_at values this method just
        wrote. Runs after _reassign_uuids, whose Game replacements this needs
        to re-capture a payload reference at the game's final uuid.
        """
        game_id_by_aggregate = {
            **dict(PlayerGame.objects.values_list("pk", "game_id")),
            **dict(Playthrough.objects.values_list("pk", "player_game__game_id")),
        }
        events = list(LibraryEvent.objects.order_by("pk"))
        for sequence, event in enumerate(events, start=1):
            offset = game_offsets[game_id_by_aggregate[event.aggregate_id]]
            event.effective_time = _shift_effective_time(event.effective_time, offset)
            event.recorded_at = (
                _midnight(event.effective_time.lower_bound)
                if event.effective_time is not None
                else FIXED_EPOCH
            )
            payload = dict(event.payload)
            if "note" in payload:
                payload["note"] = ""
            if "name" in payload:
                payload["name"] = ""
            for found in DEFAULT_WIRING.event_types.references_in(
                event.event_type, payload
            ):
                old_game_id = UUID(found.value["id"])
                new_game = Game.objects.get(
                    pk=game_replacements.get(old_game_id, old_game_id)
                )
                payload[found.key] = capture_reference(new_game)
            event.payload = payload
            event.source_metadata = {
                key: value
                for key, value in event.source_metadata.items()
                if key != "play_event_id"
            }
            event.idempotency_key = f"sample:{sequence}"
            event.actor = None
        LibraryEvent.objects.bulk_update(
            events,
            [
                "effective_time",
                "recorded_at",
                "payload",
                "source_metadata",
                "idempotency_key",
                "actor",
            ],
        )

        references = list(LibraryEventReference.objects.order_by("pk"))
        for reference in references:
            if reference.kind == "catalog.game":
                reference.referenced_id = game_replacements.get(
                    reference.referenced_id, reference.referenced_id
                )
        LibraryEventReference.objects.bulk_update(references, ["referenced_id"])

        def _mint(moment, state):
            current_ms = _floor_ms(moment)
            state["sequence"] = state["sequence"] + 1 if current_ms == state["ms"] else 0
            state["ms"] = current_ms
            return uuid7_at(
                moment, sequence=state["sequence"], entropy=random.getrandbits(_RAND_B_BITS)
            )

        def _group_replacements(rows, key):
            """One new id per distinct group, minted at that group's earliest
            recorded_at, in recorded_at order so two groups born in the same
            millisecond still get distinct sequence numbers."""
            earliest = {}
            for row in rows:
                group = key(row)
                if group not in earliest or row.recorded_at < earliest[group]:
                    earliest[group] = row.recorded_at
            state = {"ms": None, "sequence": -1}
            return {
                group: _mint(moment, state)
                for group, moment in sorted(earliest.items(), key=lambda pair: pair[1])
            }

        aggregate_replacements = _group_replacements(
            events, lambda event: event.aggregate_id
        )
        correlation_replacements = _group_replacements(
            events, lambda event: event.correlation_id
        )
        stream_replacements = _group_replacements(events, lambda event: event.stream_id)

        event_id_replacements = {}
        id_state = {"ms": None, "sequence": -1}
        for event in sorted(events, key=lambda event: (event.recorded_at, event.pk)):
            event_id_replacements[event.pk] = _mint(event.recorded_at, id_state)
        for event in events:
            event.id = event_id_replacements[event.pk]
            event.aggregate_id = aggregate_replacements[event.aggregate_id]
            event.correlation_id = correlation_replacements[event.correlation_id]
            if event.causation_id is not None:
                event.causation_id = correlation_replacements.get(
                    event.causation_id, event.causation_id
                )
            event.stream_id = stream_replacements[event.stream_id]
        LibraryEvent.objects.bulk_update(
            events,
            ["id", "aggregate_id", "correlation_id", "causation_id", "stream_id"],
        )

        reference_id_state = {"ms": None, "sequence": -1}
        event_moment_by_old_id = {
            old_id: events[index].recorded_at
            for index, old_id in enumerate(event_id_replacements)
        }
        for reference in sorted(
            references, key=lambda reference: event_moment_by_old_id[reference.event_id]
        ):
            reference.id = _mint(
                event_moment_by_old_id[reference.event_id], reference_id_state
            )
            reference.event_id = event_id_replacements[reference.event_id]
        LibraryEventReference.objects.bulk_update(references, ["id", "event_id"])

        heads = list(LibraryEventStreamHead.objects.order_by("pk"))
        for head in heads:
            head.id = stream_replacements[head.pk]
        LibraryEventStreamHead.objects.bulk_update(heads, ["id"])

        return len(events)
```
